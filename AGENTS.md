# SettleProof

PayPal AI Hackathon build, started 17 October 2026. Use only PayPal sandbox; never production endpoints or real-money actions. Do not publish or log credentials, payer personal information, private client documents or other projects' code/assets. Fixtures must be explicitly labelled synthetic.

Keep the server's deterministic evidence checks authoritative. AI may explain and draft; it must not execute financial actions or change payment facts. Unavailable data must stay unknown.

Before publishing run npm run check, npm test and npm run build. Preserve MIT licensing and third-party notices. Final hackathon submission accepts a contract and needs the user's action-time approval after the concrete build/video are reviewable.

## Git workflow

- Save meaningful changes in focused commits as work progresses, as requested by the user. Separate implementation, documentation, evidence and repository maintenance when they are independent changes.
- Review staged changes and verify Git status before finishing. Keep existing history; do not rewrite old commits to manufacture a split.
- Keep credentials, raw capability links, private account screenshots, local memory, dependencies, generated caches and rendered exports out of Git.
- Push reviewed commits to the existing origin within this project's authorized public publishing scope.
